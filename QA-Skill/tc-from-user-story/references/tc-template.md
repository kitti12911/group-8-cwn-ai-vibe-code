## 3. รายละเอียด test case

### TS-16 · ส่งฟรีเมื่อครบ 5,000 บาท (US-16 · P1)

#### TC-16-02 · ยอด 5,000 บาทพอดี ส่งฟรี
- **เงื่อนไขก่อนเริ่ม:** ตะกร้าว่าง · ที่อยู่จัดส่งกรุงเทพฯ
- **ข้อมูลทดสอบ:** สินค้าพร้อมส่งราคา 2,500 บาท × 2 = 5,000 บาท (ราคาสมมติ หาสินค้าจริงที่รวมได้ยอดนี้ก่อนรัน)
- **ขั้นตอน**
  1. ใส่สินค้าลงตะกร้าจนยอดสินค้า = 5,000 บาท
  2. ไปหน้าทบทวนคำสั่งซื้อ
- **ผลที่คาดหวัง:** บรรทัดค่าส่ง = 0 บาท หรือ "ส่งฟรี" · ยอดที่ต้องจ่าย = 5,000 บาท
- **ที่มา:** [เว็บ] หน้าแรก "ครบ 5,000 ขึ้นไป"
- **หมายเหตุ:** ขึ้นกับ K1 — ถ้าร้านยึดคำว่า "เกิน 5,000" (หน้าการจัดส่ง) ผลที่คาดหวังจะกลับเป็น "มีค่าส่ง" · Q1 นับก่อน/หลังส่วนลด
