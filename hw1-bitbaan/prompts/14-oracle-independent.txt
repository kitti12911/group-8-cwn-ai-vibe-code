  export const ORACLE_READY = true;
  export function quote(input: OracleInput): OracleQuote

กติกาที่ห้ามพลาด
  - คำนวณด้วยจำนวนเต็มทุกขั้น ห้ามใช้ทศนิยมลอยตัว (float) เลย
    ราคาสินค้า ส่วนลด และยอดชำระเป็นบาทเต็ม · คืนค่าออกมาเป็น "สตางค์" (คูณ 100)
    มีแค่ vat และ preVat ที่มีเศษสตางค์
  - ส่วนลดที่เป็นเปอร์เซ็นต์ ให้ปัดลงเป็นบาทเต็มตามสมมติฐาน A-11
  - ลำดับการคิด: ราคาป้าย → flash sale (G1) → ชุดประกอบ (G2) → ส่วนลดสมาชิก (G3)
    → คูปอง (G4) → + ค่าประกอบ → + ค่าส่ง = ยอดชำระ
  - VAT = ปัดครึ่งขึ้น(ยอดชำระ × 7 ÷ 107, 2 ตำแหน่ง) คิดครั้งเดียวทั้งบิล · preVat = ยอดชำระ − VAT
  - เวลาที่รับเข้ามาเป็น ISO 8601 พร้อม +07:00 ให้ตีความเป็นเวลาไทยเสมอ
  - ถ้าคูปองใช้ไม่ได้ ให้ตั้ง couponRejected = true และ couponAmount = 0 ไม่ต้องโยน error
  - เขียนโค้ดเองทั้งหมด ห้ามคัดลอกจากที่อื่น

สิ่งที่ต้องรายงานกลับมาด้วย
  - กฎข้อไหนที่กำกวมจนต้องเดา เดาว่าอะไร และเดาจากประโยคไหน
  - ข้อไหนที่ REQUIREMENTS.md ขัดกันเอง หรือขัดกับ INTERVIEW.md
