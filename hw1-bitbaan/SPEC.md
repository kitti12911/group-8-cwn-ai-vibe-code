## 1. วิธีเปิดเว็บ

ต้องมี Docker Desktop · คำสั่งเดียวกันทั้ง Windows (PowerShell) และ macOS (Terminal)

```bash
docker compose up -d --build              # เปิด http://localhost:3000
curl -X POST localhost:3000/api/test/reset # ล้างข้อมูลกลับเป็น seed
docker compose down -v                    # ปิดและลบข้อมูลในฐานข้อมูล
```

| container | ทำอะไร | พอร์ต |
| --- | --- | --- |
| `bitbaan-frontend` | nginx เสิร์ฟหน้าเว็บที่ build แล้ว · ส่ง `/api/*` ต่อให้ backend | `3000` → 80 |
| `bitbaan-backend` | Go API · ตอน build รัน `go test ./internal/...` ก่อน ถ้า test แดง build ไม่ผ่าน | ภายใน `8080` (ไม่เปิดออกเครื่อง) |
| `bitbaan-db` | PostgreSQL 16 · ผู้ใช้/รหัส/ฐาน `bitbaan` · volume `db-data` | `5434` → 5432 |

| ตัวแปร (backend) | ค่าใน compose | ค่าเริ่มต้นในโค้ด | ความหมาย |
| --- | --- | --- | --- |
| `TEST_MODE` | `1` | `0` | เปิด `/api/test/*` และ header `X-Test-User` · ล็อกเวลาเว็บที่ 13 พ.ย. 2026 10:00 ตอนเริ่ม · `0` = route ทดสอบตอบ `404 NOT_FOUND` และใช้เวลาจริง |
