## A หน้า/สถานะที่เจอ (เติม)

- `/cart` ช่อง "โค้ดส่วนลด · ใช้ได้ออเดอร์ละ 1 โค้ด" + ปุ่ม "ใช้โค้ด" · สถานะโค้ด 3 แบบ: ว่าง / "ใช้โค้ด X แล้ว · ลด ฿…" / "โค้ด X ใช้ไม่ได้: …" (01, 04)
- `/cart` → confirm dialog ของเบราว์เซอร์ตอนเปลี่ยนโค้ด
- `/checkout/BB-261113-0007` บรรทัดคูปอง −200.00 · ปุ่ม "ชำระด้วย PromptPay QR" · "ชำระด้วยบัตรเครดิต / เดบิต" (02)
- หลังจ่าย: "ชำระแล้ว · รอแพ็กของ" · ปุ่ม "ดูใบกำกับภาษี" · "ยกเลิกและขอคืนเงิน"
- ตะกร้าคนไม่ล็อกอิน: ช่องชื่อ-นามสกุล เบอร์โทร อีเมล (05)

## B ฟีเจอร์ (เติม)

- คูปองตัดช่องว่างและไม่สนตัวพิมพ์ (`gamer5` ที่มีช่องว่างหน้า-หลังก็ใช้ได้)
- โค้ดค้างใน localStorage ข้ามการล็อกเอาต์ (ตะกร้าคนไม่ล็อกอินโหลดมาพร้อม NEWBIT200 ของคุณนิดา แล้วขึ้นใช้ไม่ได้)
- ใบสรุปราคามีบรรทัดอธิบาย "คิดส่วนลดตามลำดับ flash sale → ชุดประกอบ → สมาชิก → คูปอง"

## D ความเสี่ยง

1. quote ตอบ APPLIED ทั้งที่ NEWBIT200 ถูกกันไว้ในออเดอร์ PENDING อื่น → ลูกค้าเห็น "ลด ฿200" แต่กดสั่งแล้วโดน 409 · สับสน (P2)
2. ซื้อด้วย NEWBIT200 → จ่าย → ยกเลิก → ได้เงินคืนเต็ม 2,050 แล้วใช้ NEWBIT200 ได้อีก · วนได้เรื่อย ๆ ไม่เสียเงิน แต่ถ้ายกเลิกบางชิ้นหรือคืนของแล้วโค้ดคืนด้วย อาจได้ส่วนลดซ้ำ (ส่งต่อ C6)
3. โค้ดค้างข้ามผู้ใช้บนเครื่องเดียวกัน (localStorage) · ไม่ได้ส่วนลด แต่เห็นโค้ดของคนก่อน
4. กด "ใช้โค้ด" ตอนช่องว่าง ไม่มีอะไรตอบ ลูกค้าอาจคิดว่าเว็บค้าง
5. ไม่ได้ทดสอบ: E50 ปล่อยหมดเวลา (CX) · GAMER5 กับ Silver/Gold/Business (C2/C4) · ช่วง flash (CX)
6. นอก charter: สั่งส่งปกติตอนยังไม่เลือกจังหวัดได้ (ระบบใส่ "กรุงเทพมหานคร" ให้เอง) · ส่งต่อ C4

## E คำถามถึงทีม

### ถามร้าน

1. ข้อความเหตุผลต้องตรงคำไหม · เว็บใช้ "ต้องเข้าสู่ระบบก่อนใช้โค้ดนี้" และ "โค้ดนี้ใช้ได้เฉพาะการ์ดจอและจอ" ยาวกว่าที่ร้านให้ไว้
2. พิมพ์โค้ดตัวเล็ก หรือมีช่องว่างหน้า/หลัง ให้ถือว่าใช้ได้ไหม
3. ลูกค้ายกเลิกออเดอร์แรกที่จ่ายแล้ว ควรได้ NEWBIT200 คืนไหม
4. คืนของออเดอร์แรก (หลังได้รับ) แล้ว ถือว่ายังเป็น "ออเดอร์แรก" อยู่ไหม
5. ใส่โค้ดผิดแล้วกดสั่ง ให้หยุดและบอกเหตุผล (ตอนนี้) หรือสั่งต่อโดยไม่มีโค้ด

### ถามคนสร้างเว็บ

1. ตอนมีออเดอร์ PENDING ใช้ NEWBIT200 อยู่ ทำไม `/api/quote` ยังตอบ APPLIED · ควรบอกว่า "ถูกใช้ไปแล้ว"
2. กด "ใช้โค้ด" ตอนช่องว่าง ควรขึ้นข้อความอะไร
3. ล็อกเอาต์แล้วควรล้างโค้ดในตะกร้าไหม
4. ส่ง `coupon` เป็น array ได้ `INVALID_JSON` · ตั้งใจให้เป็น error นี้ หรือควรเป็น `COUPON_REJECTED`
