รัน **แผนทดสอบของตัวเองแบบไม่แก้ test เลย** กับเว็บที่เปิดโหมดบั๊ก แล้วดูว่า TC ไหนแดง

## ส่วนที่ 2 · บั๊กจากทีมคู่ (`BUG_MODE=2`)

⏳ รอผู้สอนประกาศคู่ทีม · เมื่อได้ patch มาแล้วให้ทำตามนี้

1. ให้คนนอกทีม `git apply` patch **โดยไม่เปิดดู diff**
2. `BUG_MODE=2 docker compose up -d --build backend`
3. `cd e2e && EXPECT_BUG_MODE=2 npx playwright test tests race property` — **ห้ามแก้ test**
4. เติมตารางด้านล่าง แล้วสำหรับตัวที่พลาด ให้โยงกับ mutant ที่รอดใน `MUTATION-REPORT.md`
